# BookManager - Proyecto Educativo

Este proyecto es un **sistema de gestión de libros** creado con fines educativos, siguiendo el patrón **MVC**.  
Permite a los usuarios interactuar con los libros a través de comentarios, mientras que el administrador gestiona los libros de manera completa.

## Descripción

BookManager permite gestionar libros y comentarios en una aplicación web, aprendiendo conceptos clave de desarrollo web y MVC:

- Separación de lógica, vista y controlador
- CRUD completo (Crear, Leer, Actualizar, Eliminar)
- Gestión de usuarios y roles (usuario y administrador)
- Validaciones básicas y manejo de formularios

## Funcionalidades

### Para usuarios

- Visualizar la lista de libros
- Consultar detalles de cada libro
- Añadir comentarios a los libros

### Para administrador

- Añadir nuevos libros
- Editar libros existentes
- Eliminar libros
- Gestionar comentarios si es necesario

## Tecnologías y herramientas

- PHP (puro o framework educativo)
- MVC como patrón de diseño
- HTML, CSS y JavaScript para la interfaz
- Base de datos MySQL
- Gestión de sesiones y roles de usuario
